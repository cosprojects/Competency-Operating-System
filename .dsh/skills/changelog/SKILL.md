# Как выполнять

1. **Только по явной команде.** Не логируй по своей инициативе, после других задач, по таймеру или «на всякий случай». Нет просьбы — не запускай ни `changelog:collect`, ни `changelog:apply` и не трогай `state.json`.
2. Прочитай проектный контракт `agents/AGENTS-changelog-session.md` целиком — он главнее этого файла.
3. Действуй по нему: `npm run changelog:collect` → прочитай дайджест → собери запись `{ date, title, description }` → `npm run changelog:apply -- --entry <файл>` → `npm run changelog:check` и `npm run typecheck`.
4. Источники — только дайджест (сессии DSH + git) и существующий `apps/web/src/content/changelog.ts`. Не выдумывай изменения, которых нет в дайджесте.
5. Если дайджест говорит «Изменений не найдено» — не создавай запись и так и скажи.
6. В ответе покажи дату, название и три предложения описания; отметь, что запись добавлена или заменена.
