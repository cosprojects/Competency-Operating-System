# AGENTS-description-writer

Ролевой контракт субагента описаний AXIONA COS. Читается перед генерацией описаний профессий,
компетенций, знаний и навыков.

## Задача

Для выбранной профессии (или всех) собрать короткие информативные описания:

- **профессия** — фокус специалиста и вклад в продукт, без шаблона «структура компетенций»;
- **компетенция** — что специалист способен понимать/делать, в каком контексте и с каким результатом;
- **знание** — суть понятия/принципа и зачем оно нужно, без префикса «Понимание:»;
- **навык** — действие + объект + критерий качества, без префикса «Умение:».

## Правила

1. Использовать только переданный контекст: названия, определения, компоненты, источники.
   Не придумывать инструменты, стандарты, цифры, цитаты и факты.
2. Писать по-русски, одна строка, 1–2 предложения, без markdown и списков.
3. Не повторять название сущности в начале описания.
4. Не перечислять стек инструментов; конкретные инструменты — только если без них теряется смысл.
5. Для знаний и навыков минимальная длина — 60 символов, для компетенций — 80, для профессий — 90.
6. Вернуть только JSON по схеме; при сомнении — более осторожная формулировка, а не выдумка.

## Контекст

- Источники правды: `model/professions/views/*.json` (описание профессии),
  `canonical/uxui.json` + `model/competencies-extra.json` (компетенции),
  `catalog/it.json` (знания/навыки тегов).
- Материалы и evidence: `model/learning-source-links.json`, `learning-sources/registry.json`,
  компоненты/теги accepted-блоков.
- Не редактировать generated `model/competencies.json` вручную — после изменений запускать
  `npm run model:sync`.

## Команды

```bash
npm run descriptions:agent -- --profession aidesigner            # dry-run, before/after
npm run descriptions:agent -- --profession aidesigner --write    # применить
npm run descriptions:agent -- --profession all --write           # раскатка
npm run descriptions:validate                                   # проверка без LLM
```

Агент включён в `npm run aggregate` (стадия после `model:sync`); отключается `--no-descriptions`.
