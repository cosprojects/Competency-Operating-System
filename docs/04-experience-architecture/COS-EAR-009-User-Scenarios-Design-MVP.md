# COS-EAR-009 — Логика взаимодействия и сценарий MVP

## 1. Назначение

Документ описывает, **как устроено взаимодействие**: какие шаги проходит человек, какие состояния возможны, по какому условию происходит переход и что видно на экране в каждый момент.

Тексты здесь не пишутся: содержательные сообщения генерирует модель по контрактам `COS-COM-008`, ориентиры тона — в `COS-SCN-*`. Композиция экрана — `COS-EAR-008`. Служебные ситуации — `COS-EAR-010`.

## 2. Модель потока

Четыре шага, 7–10 минут.

| Шаг | Название | Время | Задача шага | Результат |
|---|---|---:|---|---|
| S1 | Кто вы и куда | 2:00 | Понять текущее положение и цель | трек, цель, уровень, материалы |
| S2 | Материалы и кейс | 3:30 | Собрать доказательства: факты и свободный ответ | подтверждённые факты, оценка кейса |
| S3 | Регистрация | 1:00 | Отдать email за полный разбор | пользователь, привязка сессии |
| S4 | Оценка и рекомендации | 3:00 | Показать сильные и слабые стороны и что делать по цели | паспорт, рекомендации |

**Продукт не обучает и не строит карту из графов.** Шаг S4 заканчивается оценкой и рекомендациями; проверочного задания на недели в MVP нет (`COS-RES-008`, Решение E).

## 3. Состояния и переходы

```
S0 Landing ──▶ S1 Setup ──▶ S2 Evidence ──▶ S3 Gate ──▶ S4 Result
                   │             │             │            │
                   └─ назад ─────┘             └─ назад ────┘
```

| Переход | Условие | Что происходит |
|---|---|---|
| S0 → S1 | нажата кнопка начала | создаётся анонимная сессия |
| S1 → S2 | выбраны текущий трек, цель и уровень | сессия сохраняет ответы, начинается разбор |
| S2 → S3 | подтверждены факты (или их нет) и отправлен ответ на кейс | рассчитывается состояние |
| S3 → S4 | переход по ссылке из письма | сессия привязывается к пользователю |
| S4 → S4′ | повторный заход | результат показывается с датой расчёта |
| назад | на любом шаге до S3 | данные шага сохраняются, оценка не сбрасывается |

**Возврат назад** разрешён до отправки ответа на кейс. После отправки шаг S2 закрыт: иначе человек увидит оценку до того, как она посчитана.

## 4. Шаг S1 — Кто вы и куда

**Что нужно собрать.** Текущий трек, цель, уровень опытности. Целевой трек — только при цели «сменить направление». Материалы — необязательны.

**Порядок и условия.**

| Блок | Когда показывается | Обязателен |
|---|---|---|
| Текущий трек (6) | всегда | да |
| Цель (3) | после выбора трека | да |
| Целевой трек (6) | только при цели «сменить направление» | да, если показан |
| Уровень опытности (4) | после выбора цели | да |
| Самооценка по узлам (3–6) | после выбора уровня | да |
| Материалы: файлы и ссылки | всегда, после самооценки | нет |
| Согласие и запуск | всегда | да |

**Состояния кнопки запуска.**

| Состояние | Условие |
|---|---|
| Неактивна | не выбраны трек, цель или уровень |
| Активна | обязательные поля заполнены |
| Загрузка | идёт создание сессии и переход |
| Ошибка | сессия не создалась; повтор |

**Валидация.** Ссылка проверяется на формат при вводе; недоступная ссылка помечается, но не блокирует запуск. Файл неподдерживаемого формата отклоняется с объяснением и предложением описать опыт текстом.

**Что видно на экране.** Канвас, центральная секция с формой, плашка ввода. Сайдбаров нет: данных для них ещё нет.

## 5. Шаг S2 — Материалы и кейс

Два блока, порядок фиксирован.

**Блок 1. Факты.**

| Условие | Поведение |
|---|---|
| Материалы есть | показываем найденные факты с фрагментом-основанием; каждый можно подтвердить или поправить |
| Материалов нет | один вопрос о прошлом опыте вместо блока фактов |
| Фактов не нашлось | сообщение, что подтверждающих материалов нет, и переход к вопросу |

Факты не участвуют в расчёте до подтверждения. Удаление материала в любой момент отзывает выводы, сделанные на его основании (`COS-ADE-120`).

**Блок 2. Кейс.**

- Одна ситуация из выбранного трека, полоса по уровню: `L0`/`L1` → `ENTRY`, `L2`/`L3` → `PRACTICE`.
- Ответ — свободным текстом, до 2200 символов, до трёх минут. Черновик сохраняется.
- Рубрика из четырёх пунктов человеку не показывается.
- Пока ответ не оценён, чат не подтверждает и не опровергает пункты (`COS-RES-008`, §7.4).

**Переход дальше.** Кнопка отправки активна при непустом ответе. После отправки — S3.

**Что видно.** Канвас, центральная секция с фактами и кейсом, плашка. Слева появляется паспорт в состоянии «собирается»: названия узлов видны, значения закрыты. Справа — развитие: собранный контекст ответов.

## 6. Шаг S3 — Регистрация

**Что видно.** Частичный результат: 1–2 сильные стороны и одна зона роста с уровнями. Остальное под блюром.

**Условие перехода.** Ввод email и переход по ссылке из письма. Пароля нет.

| Состояние | Поведение |
|---|---|
| Email не введён | кнопка неактивна |
| Email введён | кнопка активна |
| Письмо отправлено | подтверждение и повторная отправка с задержкой |
| Адрес занят | предложение войти по письму |
| Ссылка устарела | запрос нового письма |

**Что видно.** Тот же канвас; центральная секция показывает блок приглашения; паспорт слева частично раскрыт; развитие справа.

## 7. Шаг S4 — Оценка и рекомендации

**Состав экрана.**

1. **Сильные стороны.** Узлы с подтверждённым уровнем и уверенностью.
2. **Слабые стороны.** Узлы, где самооценка выше подтверждённого, и узлы без подтверждения.
3. **Калибровка.** Объяснение расхождений.
4. **Рекомендации по цели.** Содержание зависит от выбора на S1.

**Ветки рекомендации.**

| Цель | Что показывается | Какие данные нужны |
|---|---|---|
| Сменить направление | что переносится в целевой трек и почему; что добрать | связи с весом переноса, целевой трек |
| Повысить грейд | что уже соответствует следующему уровню; что отстаёт | уровни узлов, требования следующего |
| Подтянуть слабые стороны | приоритетный список узлов с разрывом и основанием | `calibrationDelta`, подтверждения |

**Чего на экране нет.** Уроков и обучающих материалов; карты графа; задания на 1–2 недели.

**Что видно.** Полный паспорт слева; рекомендации в центральной секции; развитие справа; плашка доступна.

## 8. Данные между шагами

| Данные | Где создаётся | Кто использует |
|---|---|---|
| `current_track_id` | S1 | S2 (кейс), S4 (паспорт) |
| `goal_type` | S1 | S4 (ветка рекомендации) |
| `target_track_id` | S1, только при смене | S4 (перенос и разрыв) |
| `self_anchor_level` | S1 | S2 (полоса кейса), S4 (калибровка) |
| `self_ratings[]` | S1 | S4 (калибровка) |
| материалы и ссылки | S1 | S2 (факты) |
| `confirmed_facts[]` | S2 | S4 (подтверждения) |
| `case_free_text`, `case_rubric_matches[]` | S2 | S4 (уровень, калибровка) |
| `user_email` | S3 | привязка сессии |

## 9. Ошибки и восстановление

| Ситуация | Что происходит | Куда возвращает |
|---|---|---|
| Сессия не создалась | сообщение и повтор | S0 |
| Материалы не прочитаны | часть фактов отсутствует, разбор продолжается | S2 |
| Кейс не отправлен | черновик сохранён | S2 |
| Модель недоступна | авторские заготовки сообщений | текущий шаг |
| Письмо не пришло | повторная отправка | S3 |
| Сессия истекла (30 дней) | предложение пройти заново | S0 |

## 10. Что в какой зоне

| Шаг | Рельс | Паспорт | Центральная секция | Развитие | Плашка |
|---|---|---|---|---|---|
| S1 | есть | нет | форма настройки | нет | есть |
| S2 | есть | «собирается» | факты и кейс | контекст ответов | есть |
| S3 | есть | частично раскрыт | приглашение | контекст | есть |
| S4 | есть | полный | оценка и рекомендации | прогресс и перенос | есть |

Сайдбары прирастают: на S1 их нет, на S2 появляются в свёрнутом виде, на S4 раскрыты.

## 11. Вне MVP

- Управление направлениями в профиле.
- Пароль и расширенная аутентификация.
- Английская версия.
- Карта графа на канвасе.
- Проверочные задания и обучающие материалы.
- Платный уровень: модель монетизации переопределяется (`COS-RES-008`, Решение D).
