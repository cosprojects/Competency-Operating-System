# COS-BP-017 — оценка рынка для инвестора

## 1. Рамка

- **Россия — только тестовая площадка.** Русскоязычное дизайн-сообщество даёт обратную связь и проверку learning loop; **выручку в РФ не планируем**.
- **Запуск — из Беларуси.** База разработки/операций; первый платный рынок — **Казахстан**, затем Узбекистан/другие страны СНГ; Европа (EU/UK) — **English first**. Текущий юрлицо-оператор теста — самозанятый РФ (НПД); для инвестиций/платежей нужно отдельное юрлицо (Казахстан/ЕС).
- Языки: русский — СНГ; английский — Европа. Продукт один, контент/цена/каналы локализуются.

Это меняет рынок: РФ не входит в TAM/SAM/SOM, кроме тестовых пользователей.

## 2. Почему сейчас

| Сигнал | Факт | Источник |
|---|---|---|
| Европа: онлайн-образование | $103,9 млрд (2025) → $253,95 млрд (2034), CAGR 10,44% | S-38 |
| ЕС: взрослое обучение | 39,5% (2022); цели 47% к 2025 и 60% к 2030 | S-39 |
| СНГ: взрослое онлайн-ДПО | Казахстан и Узбекистан растут; цифровые профессии — программирование, маркетинг, дизайн; Узбекистан — быстрее | S-40 |
| Беларусь: IT-база | HTP: выручка $3 млрд, экспорт +12%, 61 тыс. сотрудников | S-41 |
| AI меняет навыки | 39% навыков изменятся к 2030; 19 млн jobs created / 9 млн displaced | S-22 |
| AI-роли | AI engineers №1, AI consultants №2, AI/ML researchers №5 (US) | S-23 |

**Вывод:** Европа — большой растущий рынок с высоким WTP; СНГ — быстрый рост и дефицит цифровых навыков; Беларусь — удобная база запуска. РФ — тест, не рынок.

## 3. Сегменты

### 3.1. Тест: дизайн-сообщество (РФ)

- 217 тыс. дизайнеров; 22,1 резюме/вакансию; спрос на обучение +2,3×.
- Роль: быстрый тест продукта и learning loop; **без выручки**.
- Риск: тестовая аудитория не равна платёжеспособной Европе/СНГ.

### 3.2. СНГ: взрослое онлайн-ДПО

- Казахстан — первый; затем Узбекистан, Армения, Грузия, Кыргызстан, Молдова.
- Спрос: цифровые профессии (программирование, маркетинг, дизайн), ДПО; Узбекистан — быстрый рост, десятки % в год (S-40).
- Язык: русский; цена локальная; оплата — Kaspi/Freedom Pay/ioka, см. `COS-BP-022`.
- Роль: первый платный рынок после теста.

### 3.3. Европа: career navigation / reskilling

- EU/UK, English; высокий WTP, GDPR, конкуренция.
- Сегменты: IT/AI-специалисты, дизайнеры/креаторы, карьерные переходы, L&D/outplacement.
- Язык: английский; локальные цены в EUR/GBP.
- Роль: основной рынок выручки и инвесторской истории.

## 4. TAM/SAM/SOM

### 4.1. TAM (референс)

**$103,9 млрд** — онлайн-образование Европы (2025; S-38). Широкий TAM, не адресуемый целиком.

### 4.2. SAM (bottom-up, допущения)

| Компонент | Расчёт | SAM |
|---|---|---:|
| Европа: professional development / career navigation | 3–5% от $103,9 млрд | $3,1–5,2 млрд |
| СНГ: взрослое онлайн-ДПО | допущение $0,3–0,8 млрд | $0,3–0,8 млрд |
| **Итого SAM** | | **$3,4–6,0 млрд** |

Допущения: доля профессионального развития/карьерной навигации; размер СНГ — оценка, не точная статистика. Цифры нужны для порядка, не для обещания.

## 6. Конкуренты

| Категория | Европа/СНГ | Наше отличие |
|---|---|---|
| Массовые курсы | Coursera, Udemy, LinkedIn Learning | не курс, а карта + разрыв + evidence |
| Школы | Skillbox, Netology, локальные школы | переход/рост, не «с нуля» |
| AI-курсы | мелкие игроки | методология, оценка, human review |
| Career services | консультанты, hh | масштабируемая система |
| LMS | Moodle, Open EdX | consumer-навигация |

## 7. GTM

- **Тест:** дизайн-сообщество РФ, 300–1000 пользователей, без выручки.
- **Казахстан first:** русскоязычные сообщества, Telegram, локальные партнёры/инфлюенсеры; затем Узбекистан.
- **Европа:** английский SEO, LinkedIn, карьерные консультанты, outplacement, релокационные сообщества.
- **B2B:** 3–5 пилотов после первых paid-данных.
- Платный трафик — только после CAC/LTV.

## 8. Риски

| Риск | Мера |
|---|---|
| РФ-тест ≠ платёжеспособный рынок | тест только для продукта; выручка — СНГ/Европа |
| GDPR/локальные законы | юрист ЕС/Беларуси; data map; consent |
| Язык/локализация | сначала русский СНГ + английский Европа; не все сразу |
| Платежи/карты | локальные провайдеры; проверить |
| Конкуренция Coursera/Udemy | ниша career navigation/evidence, не курсы |
| Нет поля | 15–20 интервью в СНГ/Европе; лендинг |

## 9. Вывод для инвестора

- Рынок: Европа $104 млрд, СНГ растёт; РФ — тест.
- SAM: $3,4–6,0 млрд; SOM: 15–20 тыс. регистраций к M24 (база), без выручки.
- История: «запуск из Беларуси → СНГ → Европа», а не «российский EdTech».
- Честно: поля нет; продукт есть; инвестиции — проверка retention/paid на двух рынках.
