## AXIONA / Competency Operating System

**AI-native система профессионального развития: карта компетенций → обучение → проверка → доказательства роста.**

Кирилл Невзоров, co-founder/CTO/Product Owner · Луиза Смольская, founder/CEO

`app.axiona.world` · hi.axiona@protonmail.com

## Проблема

- Человек не понимает, каких компетенций ему не хватает для желаемой роли.
- Курсы фрагментированы: после них нет карты, проверки и доказательств.
- AI меняет требования: 39% навыков изменятся к 2030 (WEF).
- IT-специалисты под риском: 26% опасаются сокращений, 34% в поиске (hh.ru/PurpleSchool).

## Решение

Один контур: **цель → диагностика → разрыв → путь → микро-урок → квиз → проект/evidence → AI-фидбек → прогресс → следующий шаг**.

Не школа и не job board: слой навигации и доказательств между человеком, обучением и работой.

## Продукт сейчас

- 13 профессий, 132 компетенции в модели, 131 опубликована, 292 связи.
- Production `app.axiona.world`: карта, профиль, сохранения, статусы, отзывы.
- QA: 77/79 PASS, 0 FAIL; регистрация закрыта — сначала тест на дизайн-сообществе.
- Следующий слой: диагностика, уроки, квизы, evidence, Pro.
