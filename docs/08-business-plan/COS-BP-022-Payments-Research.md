# COS-BP-022 — платежи: что доступно и что делать

> Не юридическая и не налоговая консультация. Проверить с юристом/бухгалтером и провайдером.

## 1. Исходная точка

- Сейчас оператор — **самозанятый РФ (НПД)**, продукт тестируется в РФ, оплат нет.
- Для инвестиций и международных продаж НПД не подходит: нет долей, ограничения, сложно принимать платежи из ЕС/СНГ.
- Нужно юрлицо и платёжный контур **до первых платных пользователей**, а не после.

## 2. Варианты

| Вариант | Для чего | Плюсы | Минусы |
|---|---|---|---|
| **Казахстан: ТОО + Kaspi Pay / Freedom Pay / ioka / Wooppay** | СНГ, KZT, локальные карты | локальный рынок, Kaspi QR 0,95%, Freedom Pay принимает иностранные карты | нужен казахстанский ТОО/счёт; интеграция; налоги |
| **ЕС: ООО + Stripe/Adyen/Mollie** | Европа, EUR/GBP | стандарт для SaaS, подписки | нужна ЕС-компания, банк, GDPR; не быстро |
| **Merchant of Record: Paddle / FastSpring / 2Checkout** | Европа + СНГ без своей ЕС-компании | MoR берёт налоги/платежи, 225 стран, 5%+$0,50 | не все принимают основателей из РФ/Беларуси; комиссия; меньше контроля |
| **Stripe Atlas (US LLC)** | Европа/глобально | быстрое US-юрлицо, Stripe | доступность платежей для RF/BY основателей не гарантирована; налоги/банк |
| **Беларусь: HTP + валютный счёт** | База запуска | HTP-режим, IT-команда | санкционные/банковские ограничения; не все провайдеры |

## 3. Что известно по провайдерам

- **Paddle (MoR):** 225 стран, **5% + $0,50** за продажу; в списке стран Paddle **Казахстан — supported**, **Беларусь/Россия — unsupported** (проверить eligibility основателя и продажи). Источник S-42.
- **Kaspi Pay:** QR-платежи, ставка **0,95%**; сильный локальный охват Казахстана, но API меньше подходит для сложных подписок. **Freedom Pay** — локальный агрегатор, принимает domestic + foreign cards; **ioka** — подписки, Apple/Google Pay. Источник S-43.
- **Stripe Atlas:** US LLC «из любой страны», но это не гарантирует платёжный аккаунт для основателя из РФ/Беларуси; нужна проверка. Источник S-44.
- **MoR-рынок:** Paddle, FastSpring, 2Checkout, PayPro Global, Dodo, Polar и др.; комиссии 3,5–10%. Источник S-45.

## 4. Рекомендация

**Двухконтурная схема:**

1. **Казахстан — первый платный рынок.** ТОО в Казахстане + локальный эквайринг (Kaspi Pay для KZT + Freedom Pay/ioka для карт/подписок). Это соответствует решению «Казахстан перспективнее» и даёт локальные платежи без ЕС-юрлица.
2. **Европа — English, EUR/GBP.** either:
   - ЕС-компания (Эстония/Литва/Польша) + Stripe/Mollie; **или**
   - MoR (Paddle/FastSpring) для старта, если он принимает основателя/юрлицо.
3. **Беларусь — операционная база/разработка**, но не единственный платёжный контур; HTP/валютный счёт — проверить.
4. **РФ — только тест, без оплат.** НПД остаётся для тестового этапа, но не для инвестиций/выручки.

**Практический порядок:**

- До инвестиций: протестировать спрос без оплат, выбрать Казахстан/ЕС юрлицо.
- T1: Казахстан ТОО + Kaspi/Freedom Pay; Европа — MoR-пилот (если доступен).
- T2: ЕС-компания + Stripe/Mollie, если Европа даёт выручку.

## 5. Что это значит для бюджета и инвестора

- Юрлицо/банк/платежи: **$3–8 тыс.** разово + 1–2% транзакций (MoR — 5%+).
- 10 млн ₽ ($120 тыс.) — бюджет без запаса на два юрлица; нужно либо начать с Казахстана + MoR, либо добавить $10–15 тыс.
- Инвестору показать: «платежи — не “потом”, а элемент T1; текущий НПД РФ — только тест».

## 6. Открытые вопросы

1. Казахстан: ТОО или партнёрство с локальной компанией?
2. Paddle/FastSpring: принимают ли основателя/юрлицо из Беларуси/РФ? Нужен pre-check.
3. Европа: ЕС-компания сразу или MoR до PMF?
4. Кто отвечает за налоги/возвраты/чарджбеки?
5. Нужен ли эквайринг в Беларуси или только операционная база?
