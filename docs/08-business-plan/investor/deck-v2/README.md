# AXIONA — Investor deck 2026-11 · Казахстан first

Современная версия инвесторского питча на визуальном языке AXIONA: светлая
структура, точечная бумага, hairline-связи, индиго-акцент и карта-схема вместо
политических границ. 14 слайдов, 16:9, 10–12 минут.

## Визуальная система

Токены — из `apps/web/src/app/globals.css`: `--ink #132238`, `--muted #5f6f85`,
`--bg #f8fafc`, `--accent #4f46e5`, `--accent-sky #0ea5e9`, radius 12/16/24.
Шрифт — Geist (variable), встроен в HTML как data URI: deck не зависит от системного шрифта
и одинаково рендерится при открытии файла с диска. Заголовки — 40 px: большинство слайдов
держит заголовок в одну строку, длинные — в две с сбалансированным переносом.
Логотипы — `apps/web/public/brand/*.svg` без перерисовки.
Иконки — линейные из `apps/web/src/components/icons.tsx` (map/lesson/quiz/chart)
плюс `gap` (разрыв) и `evidence` в том же стиле, 24×24, stroke 1.6.

Карты `assets/map-europe-cis*.svg` и `assets/map-kazakhstan.svg` — точечная
матрица из Natural Earth 110m (`scripts/deck/data/ne-110m-trim.geojson`), без
границ, флагов и орнаментов. Генерируются `node scripts/deck/maps.mjs`.

Скриншоты — из `docs/design/screens/` (карта профессии, сохранённое,
карточка компетенции). Портреты заменены инициалами ЛС/КН — фото в репозитории нет.

## Сборка

```sh
npm run deck:build      # карты → HTML → PDF → PNG → contact sheet → verify
npm run deck:verify     # только проверка готового HTML/PDF/PNG
npm run deck:maps       # перегенерировать карты
npm run deck:audit      # замеры раскладки по слайдам (title lines / overflow / overlaps)
```

Контент и композиция — `scripts/deck/decks/axiona-pitch-ru-2026-11.mjs`.
Примитивы, CSS и режимы просмотра — `scripts/deck/engine.mjs`.

## Проверка вёрстки

`npm run deck:verify` проверяет:

1. нигде нет цен / тарифов / выручки / платящих / оплат — ни на слайдах, ни в заметках;
2. 13 / 132 / 131 / 292 и $120 тыс. совпадают с copy deck, $84 + $36 = $120;
3. старые цифры РФ-версии ($110–120 тыс., 500 платящих, 590/990 ₽ и т.п.) не просочились;
4. есть логотип, 3–5 скриншотов, инициалы, 2 карты, 6 иконок;
5. layout-audit: ни один блок не залезает на футер и блоки не перекрываются;
6. PDF — 14 страниц, PNG — 14 файлов 2560×1440, у каждого слайда есть заметки.

Текущий статус — **43/43 OK** (см. `VERIFY.md` и `layout-audit.json`).

## Следующая презентация

Движок переиспользуемый: скопируй content-модуль в
`scripts/deck/decks/<name>.mjs`, собери слайды из примитивов `engine.mjs`
(`slideShell`, `stat`, `card`, `route`, `timeline`-классы, `screenshot`,
`person`, `donut`, `takeaway`) и запусти
`node scripts/deck/build.mjs --deck <name>`. Палитра и сетка не меняются —
меняется только контент.
