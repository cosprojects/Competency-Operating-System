# COS-RES-004 — Валидация, правовые рамки, ограничения и библиография

## 1. Назначение

Документ фиксирует, что нужно сделать, прежде чем называть входную оценку валидированной, какие правовые рамки ограничивают её применение в ЕС, США и России, что осталось непроверенным и на какие источники опирается весь набор.

## 2. План валидации

Валидация — это не один тест, а последовательность этапов. Параметры выборок ниже — **проектные предложения**, которые должен утвердить психометрист; они не выводятся напрямую из литературы.

### Этап 0. Экспертное ревью содержания

- Ревью психологом или психометристом: соответствие конструктов задаче, корректность формулировок, отсутствие клинических интерпретаций.
- Проверка, что ни один пункт не выходит за рамки заявленного использования.
- **Условие выхода:** подписанное заключение эксперта; без него никакие публичные заявления невозможны.

### Этап 1. Понятность и перевод (для русскоязычной версии)

- Обратный перевод и когнитивные интервью с представителями целевой аудитории.
- Ориентир: несколько раундов по 10–20 человек, до устранения систематических непониманий.
- Для заимствованных инструментов — проверка инвариантности измерения относительно оригинальной версии там, где есть такая возможность.

### Этап 2. Надёжность

| Метрика | Что считается | Ориентир |
|---|---|---|
| Внутренняя согласованность (α, ω) | Каждая шкала | Не ниже .70 для шкал, влияющих на выводы; для коротких фасетных шкал — выше .60 с оговоркой |
| Ретестовая надёжность (ICC) | Те же люди через 2–4 недели | Ориентир ICC ≥ .70; интервал наблюдается и публикуется |
| Условная стандартная ошибка (IRT или по группам баллов) | Диапазоны баллов | Обязательна: Стандарты требуют условные SE для решений о конкретном человеке |
| Межэкспертная согласованность рубрик для поведенческих вопросов | Кодирование примеров | Ориентир ICC ≥ .70; для цифрового формата ключевой риск |

Ориентировочный объём: не менее 300–400 завершённых прохождений для устойчивых оценок согласованности и последующего анализа структуры.

### Этап 3. Конвергентная валидность

- Якорные инструменты: BFI-2 (русская версия, `10.17323/1813-8918-2021-1-7-33`) для черт; O*NET IP (русская адаптация) для интересов; CDSE-подобные шкалы для готовности выбирать.
- Ожидания по корреляциям должны быть заявлены заранее (пререгистрация): для одноимённых конструктов разумный ориентир r ≥ .50, для смежных — r = .30–.50.
- Отдельно проверяется дискриминантная валидность: шкалы не должны коррелировать со всем подряд.

### Этап 4. Структура

- Конфирматорный факторный анализ для каждой шкалы; проверка инвариантности по полу, возрасту и (при наличии данных) по уровню образования.
- Устойчивость структуры вне крупных городов — отдельный вопрос, поскольку качество измерения вне образованных городских выборок систематически падает (`10.1126/sciadv.aaw5226`).

### Этап 5. Предсказательная и инкрементальная валидность

- Критерии: реальный прогресс пользователя (завершение Development Action, переход в следующий уровень), удержание, удовлетворённость выбранным направлением.
- Обязательно проверять инкрементальную валидность: добавляет ли каждый блок к предсказанию сверх остальных. Блок, который не добавляет, должен быть удалён — это прямое следствие требования экономии времени пользователя.
- Горизонт: минимум 3–6 месяцев наблюдения.

### Этап 6. Справедливость (fairness)

- Проверка DIF и инвариантности по подгруппам.
- Сравнение распределений и точности по подгруппам; фиксация расхождений.
- Для B2B — мониторинг adverse impact по правилу 4/5 (см. раздел 4.4).
- По Стандартам (Standard 3.0) справедливость — это вопрос валидности, а не отдельный «социальный» раздел.

### Этап 7. Непрерывный мониторинг

- Регулярная переоценка после изменений модели, промптов, версии LLM.
- Логирование оснований решений (соответствует требованиям record-keeping для high-risk систем в ЕС).

## 3. Соответствие стандартам APA/AERA/NCME

*Standards for Educational and Psychological Testing* (2014) — основной внешний ориентир. Что из них прямо влияет на дизайн:

| Требование | Как реализуем |
|---|---|
| Standard 2.0: надёжность соразмерна последствиям; ниже — если решение обратимо и подкреплено другими источниками | Входная оценка даёт гипотезу и следующий шаг, а не окончательное решение; решения обратимы |
| Условные стандартные ошибки для конкретного человека | Публикуем SEM/диапазоны, а не точные баллы |
| Сокращение формы снижает надёжность | Короткие формы используются с явной оговоркой о погрешности |
| Результаты теста не должны быть единственным основанием | Минимум два независимых источника на каждый вывод |
| Standard 3.0: справедливость — фундаментальный вопрос валидности | Этап 6 плана валидации |
| Standard 3.8: доказательства валидности для подгрупп | Анализ по подгруппам там, где позволяет выборка |
| Квалификация пользователя теста | Интерпретацию контролирует методолог/психолог; результаты не выдаются как «диагноз» |

## 4. Правовые рамки

### 4.1. Европейский союз

**AI Act (Regulation (EU) 2024/1689).**

- **Запрещено (ст. 5(1)(f)):** использование ИИ для вывода эмоций человека на рабочем месте и в образовательных учреждениях, кроме медицинских и связанных с безопасностью целей. Это прямой запрет на «определение эмоционального состояния по чату» в продукте.
- **Запрещено (ст. 5(1)(c), 5(1)(d)):** социальный скоринг на основе выведенных личностных характеристик и оценка риска правонарушения на основе профилирования личностных черт.
- **High-risk (Приложение III):** п. 3 — образование и профессиональное обучение (доступ, оценка результатов, распределение по уровням); п. 4 — трудоустройство и управление работниками (отбор кандидатов, оценка, продвижение, распределение задач на основе личностных характеристик, мониторинг поведения). Распознавание эмоций отнесено к high-risk (п. 1(c)).
- **Обязанности для high-risk:** система управления рисками (ст. 9), управление данными (ст. 10), техническая документация (ст. 11), автоматическое протоколирование (ст. 12), прозрачность и инструкции для пользователя (ст. 13), человеческий надзор (ст. 14), точность, устойчивость, кибербезопасность (ст. 15); у применяющей стороны — надзор компетентными людьми (ст. 26) и, в ряде случаев, оценка влияния на права (ст. 27); право на объяснение индивидуального решения (ст. 86).
- **Мотив законодателя:** в преамбуле прямо указано, что системы инференции эмоций вызывают серьёзные сомнения научного характера — «ограниченная надёжность, отсутствие специфичности и ограниченная обобщаемость», что может вести к дискриминационным исходам.
- **Даты применения:** регламент применяется с 2 августа 2026 года; запреты (включая ст. 5) — с 2 февраля 2025 года; обязательства по моделям общего назначения — с 2 августа 2025 года; отдельные положения по high-risk продуктам — с 2 августа 2027 года.

**GDPR (Regulation (EU) 2016/679).**

- **Ст. 9(1):** запрет обработки специальных категорий, включая биометрические данные для идентификации и данные о здоровье, кроме исключений (в том числе явное согласие, ст. 9(2)(a)). Психологическая оценка может попадать в эту категорию в зависимости от контекста.
- **Ст. 22:** право не быть объектом решения, основанного исключительно на автоматизированной обработке, если оно порождает юридические последствия или существенно затрагивает человека; ст. 22(3) — право на вмешательство человека, изложение своей позиции и оспаривание; ст. 22(4) — ограничения на использование специальных категорий.

### 4.2. США

- **NYC Local Law 144 (2021):** для автоматизированных инструментов найма требуются независимый аудит на предвзятость не реже чем раз в год, публикация сводки результатов и уведомление кандидата не менее чем за 10 рабочих дней с возможностью запросить альтернативный процесс.
- **Illinois AI Video Interview Act (820 ILCS 42):** уведомление и получение согласия до интервью, раскрытие логики работы ИИ и типов используемых характеристик, удаление видео по запросу в течение 30 дней, ежегодная отчётность.
- **EEOC Uniform Guidelines, 29 CFR § 1607.4(D):** правило 4/5 — доля отобранных для любой группы менее 80% от лучшей группы обычно рассматривается как свидетельство adverse impact.
- **Griggs v. Duke Power Co., 401 U.S. 424 (1971):** практика, нейтральная по форме, но дискриминирующая по результату, запрещена; критерий — business necessity; инструмент должен демонстрировать связь с результативностью.
- **42 U.S.C. § 2000e-2(l):** запрет корректировать баллы тестов или применять разные пороги по признаку расы, цвета кожи, религии, пола, национального происхождения.
- **Примечание о регуляторной нестабильности:** техническая помощь EEOC 2023 года по оценке adverse impact в ИИ-системах более не публикуется (страница недоступна, архивных копий нет). Правовая основа (Title VII и UGESP) при этом действует; перед запуском нужна повторная юридическая проверка.

### 4.3. Россия

**152-ФЗ «О персональных данных».**

- **Ст. 9:** согласие должно быть конкретным, предметным, информированным, сознательным и однозначным; оформляется отдельно от иных документов.
- **Ст. 10:** обработка специальных категорий (раса, национальность, политические взгляды, религиозные и философские убеждения, состояние здоровья, интимная жизнь) не допускается, кроме случаев, включая письменное согласие. Психологические данные в зависимости от контекста могут попадать в эту категорию.
- **Ст. 11:** биометрические персональные данные — только с письменным согласием.
- **Ст. 16:** запрещается принятие решений, порождающих юридические последствия или иным образом затрагивающих права и законные интересы, **на основании исключительно автоматизированной обработки**; оператор обязан разъяснить порядок принятия решения.
- **Ст. 18 ч. 5 (локализация):** при сборе персональных данных, в том числе через интернет, оператор обязан обеспечить запись, систематизацию, накопление, хранение, уточнение и извлечение данных граждан РФ с использованием баз данных, находящихся на территории России. Для русскоязычной аудитории это отдельное требование к размещению: первичная обработка не может опираться только на зарубежную инфраструктуру. Это совпадает с решением `COS-ARCH-160` держать пользовательские данные и результаты диагностики на собственном production-контуре.

### 4.4. Практические следствия для продукта

1. Эмоции не выводим (ЕС: прямой запрет).
2. Автоматические решения о человеке не принимаем; человек видит основания и может оспорить.
3. Для B2B фиксируем отдельный контур: оценка сотрудников и кандидатов — high-risk применение в ЕС, с документацией, надзором и мониторингом adverse impact. Границы контура и момент перехода личного результата в организационный — `COS-RES-006`.
4. Данные оценки храним с согласием и удаляем по запросу; объём данных минимизируем. Для граждан РФ учитываем локализацию по 152-ФЗ ст. 18 ч. 5.
5. Заявления о «научной валидации» — только после этапов 0–3 плана валидации.
6. Правовой режим определяется применением, а не инструментом: один и тот же вопросник может быть нейтральным в B2C и high-risk в B2B. Это фиксируется в методике, а не только в юридическом приложении.

### 4.5. Профессиональная этика

APA Ethics Code, разделы 9.01–9.10: заключения только на достаточных основаниях (9.01); использование инструментов в соответствии с исследованиями об их пригодности (9.02); информированное согласие (9.03); интерпретация автоматизированных результатов с учётом языковых и культурных различий и с указанием ограничений (9.06); запрет продвигать психологические методики среди неквалифицированных лиц (9.07); ответственность за автоматизированные сервисы скоринга (9.09); объяснение результатов (9.10).

## 5. Что осталось непроверенным

1. **Нет собственных данных** ни по одному этапу валидации.
2. **Русскоязычные пробелы:** отсутствуют данные по LLM-оценке на русских текстах; нет ретест-надёжности для чат-выводов; HEXACO-русская версия не имеет подтверждённой публикации о валидации; O*NET IP не имеет русской версии; ДДО и «Карта интересов» не имеют верифицированной психометрики.
3. **Закрытые первоисточники:** точные значения по BFI-2-S/XS, HEXACO, Barrick & Mount, Hurtz & Donovan, Christian et al. (SJT), Choi et al. (CDSE), Kristof-Brown et al. (P–E fit), психометрика WAIS/Raven/SB5/DAT — не подтверждены.
4. **Цифровой формат:** нет мета-аналитических данных о trade-off «число методов — удержание пользователя»; для опосредованных интервью известен штраф d = −.36…−.41, но не для асинхронного чата.
5. **Prompt injection** применительно к оценке личности прикладных исследований не имеет (сам класс атак подтверждён).
6. **Теоретическая база IQ** слабее, чем принято считать: единой CHC-модели нет.
7. Часть популярных цифр (например, «≈50% смены типа MBTI», «ICC 0.75–0.95 у LLM») первоисточниками не подтверждена и в выводах не используется.
8. **Извлечение смысла из свободных ответов на русском** не измерено: нет данных о согласии с ручным кодированием и о доле исправлений пользователем (`COS-RES-007`, раздел 9).
9. **Отвал в разговорном формате** против выборочного на русскоязычной аудитории не проверялся. Из общей литературы известно, что открытые вопросы повышают прерывание; переносить это на конкретный сценарий без пилота нельзя.

## 7. Условие публичных заявлений

Формулировки о «научно валидированной оценке», «доказанной точности» и аналогичные могут использоваться в коммуникации продукта только после одновременного выполнения трёх условий:

1. Завершено экспертное ревью психологом или психометристом (этап 0).
2. Выполнены этапы 1–3 плана валидации с опубликованными результатами (надёжность, конвергентная валидность, структура).
3. Проведён и документирован аудит справедливости, а результаты пилота воспроизведены независимо или на второй выборке.

До этого момента корректная формулировка: «предварительная оценка, которая уточняется по мере прохождения развития».
