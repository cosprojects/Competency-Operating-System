# COS-RES-023 — Дополнительные дизайнерские профессии: схемы

Документ фиксирует **этап 1** работ по расширению COS за пределы четырёх базовых дизайнерских профессий: собраны схемы (profession view + компетенции + связи) для ещё семи профессий. Блоки, приоритеты и материалы для них — следующие этапы.

## 1. Roadmap (согласован с заказчиком)

| Этап | Содержание | Статус |
|---|---|---|
| **1** | Схемы для остальных дизайнеров: дизайнер презентаций, дизайнер приложений, UX-исследователь, арт-директор, 3D-дизайнер, дизайнер интерьеров, веб-дизайнер | **сделано (этот документ)** |
| **2** | Навыки работы с нейросетями на разных этапах — добавить во **все** профессии: ресёрч, проектирование, презентации, фото/видео/аудио/контент, монтаж, сборка макетов, документация, вёрстка | запланировано |
| **3** | Новая профессия **AI-дизайнер**: инструменты, их особенности и интеграция в процесс | запланировано (финал) |

Этап 2 не смешивается с этапом 1: в текущих схемах **нет** отдельной AI-компетенции, чтобы не зафиксировать её в одном месте раньше, чем будет принят общий слой нейрокомпетенций для всех профессий.

### Логика схем

- **Дизайнер презентаций**: мышление → типографика/цвет/сетка → структура → аудитория → сообщение → данные/фактчекинг → визуализация → инструменты → защита.
- **Дизайнер приложений**: визуальные основы → платформенные гайдлайны → исследования/персоны → мобильные паттерны → IA/флоу/вайрфреймы → продвинутые прототипы → дизайн-системы/компоненты/адаптивность/доступность → кроссплатформенность, handoff и метрики.
- **UX-исследователь**: принципы и вопросы → этика → качественные/количественные методы → выборка/рекрутинг → интервью/персоны/юзабилити/эксперименты/аналитика/метрики → синтез и отчёт → применение в продукте и IA.
- **Арт-директор**: визуальные основы → айдентика → стратегия/бренд-платформа → система дизайна → бриф/бизнес → коммуникация → презентация идей → команда, наём и развитие.
- **3D-дизайнер**: основы 3D и моделирование → hard-surface/скульптинг → материалы/свет → рендер/композитинг → анимация и тайминг (переиспользуются motion-компетенции) → подача 3D-проекта.
- **Дизайнер интерьеров**: анализ пространства → эргономика → зонирование → стили/цвет → материалы/свет → визуализация → чертежи/ГОСТ → спецификации/смета → ведение проекта.
- **Веб-дизайнер**: основы и лендинги → UX-структура → визуальный слой/адаптивность → дизайн-системы/компоненты/доступность → Figma/веб-технологии/CMS/handoff/оптимизация.

### Новые профессио-специфичные компетенции (48)

- `presentation-*`: structure, audience, message, data, visualization, delivery.
- `app-*`: platform-guidelines, mobile-patterns, prototyping, native-crossplatform, metrics.
- `uxresearch-*`: principles, questions, ethics, qualitative, quantitative, recruiting, usability, synthesis.
- `artdir-*`: brand-strategy, brand-platform, brief, communication, presentation, team, hiring.
- `3d-*`: modeling, hard-surface, sculpting, texturing, lighting, rendering, compositing, presentation.
- `interior-*`: space-analysis, ergonomics, zoning, styles, materials, visualization, drawings, specs, project-management.
- `web-*`: landing, adaptive, cms, visual, performance.

Определения и learning-связи — в `model/competencies-extra.json`; `learningSourceIds` указывают на Practicum-программы.

## 5. Что пока не сделано

Это **схемы**, а не полная сборка:

- нет accepted-блоков и тегов для 48 новых компетенций → `model:validate --require-blocks` для новых профессий пока не проходит (осознанно); канвасы новых профессий строятся с синтетическими узлами без компонентов/тегов;
- нет `mapping/<profession>.json` и journal-материалов для новых профессий;
- нет priority-marks (решение по слою то же: view + `profession-competencies`, см. `COS-RES-020` §5);
- названия/определения компетенций — draft для human-review, а не приёмка.

## 7. Следующие шаги

1. **Human-review** имён, определений и связей 48 новых компетенций (схемы Этапа 1).
2. **Блоки и mapping** для 7 новых профессий (по схеме `COS-RES-020/021`), затем материалы.
3. **Этап 2**: общий слой AI/нейрокомпетенций — во все 11 профессий (ресёрч, проектирование, презентации, фото/видео/аудио/контент, монтаж, макеты, документация, вёрстка); потребует отдельного решения о гранулярности: одна сквозная компетенция или набор прикладных.
4. **Этап 3**: профессия «AI-дизайнер» — инструменты, их особенности и интеграция в процесс; собирается после стабилизации этапов 1–2.
