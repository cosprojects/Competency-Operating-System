# COS-RES-024 — Этап 2: ИИ-компетенции во всех профессиях

Документ фиксирует **этап 2**: сквозной слой навыков работы с нейросетями добавлен во все 11 профессий (10 profession views + UX/UI через canonical-путь).

## 1. Решение по гранулярности

Рассматривались варианты:

| Вариант | Плюсы | Минусы | Решение |
|---|---|---|---|
| AI-вариант каждой из 103 компетенций | максимальная точность | удвоение массива, дубли, неподдерживаемо | отклонено |
| Отдельная «AI-профессия» | просто | смешивает этапы 2 и 3; не даёт ИИ-навыков остальным профессиям | отклонено (это этап 3) |
| **Сквозной слой из 9 компетенций** | переиспользуется во всех профессиях, разные tier/order, покрывает все этапы работы | не описывает узкие профессиональные AI-приёмы | **принято** |

Слой устроен по этапам работы, а не по инструментам: основы → применение (ресёрч, визуал, видео/аудио, текст) → производство (макеты/документация/вёрстка, интеграция) → этика.

## 2. Девять компетенций слоя

| id | Компетенция | Что покрывает | Tier по умолчанию |
|---|---|---|---|
| `ai-model-landscape` | Модели и инструменты ИИ | виды генеративных моделей, возможности/ограничения, выбор под задачу | foundation |
| `ai-prompting` | Промптинг и управление моделями | структура промпта, итерации, уточнения, негативные промпты, контроль результата | foundation |
| `ai-research-synthesis` | ИИ в исследованиях и синтезе | гайды, обработка интервью, синтез данных, проверка выводов | core |
| `ai-visual-generation` | ИИ в генерации и обработке изображений | фото, иллюстрации, иконки, референсы, стиль, консистентность | core |
| `ai-video-audio` | ИИ в видео, монтаже и аудио | генерация видео/аудио, ИИ-монтаж, озвучка, музыка, синхронизация | core |
| `ai-copy-content` | ИИ в тексте, контенте и презентациях | генерация и редактура текста, контент, слайды, контроль смысла/фактов | core |
| `ai-layout-docs` | ИИ в макетах, документации и вёрстке | сборка макетов, спецификации, документация, вёрстка | core |
| `ai-workflow-integration` | Интеграция ИИ в процесс | встраивание в workflow, автоматизация рутины, контроль качества, границы применимости | core |
| `ai-ethics-rights` | Этика, авторские права и данные | права, приватность, безопасность данных, смещения, фактчекинг ИИ | core |

Профессиональные акценты задаются через tier/order в view, а не копированием компетенций: например, `ai-video-audio` — core для motion/3D/арт-дирекшена и optional для веба/интерьеров; `ai-layout-docs` — core для веба/презентаций/приложений; `ai-ethics-rights` — core для UX-исследователя.

## 3. Как слой встроен

- **10 profession views** (product, motion, graphic, presentation, appdesign, uxresearch, artdir, 3ddesigner, interior, webdesigner): секция «ИИ на этапах работы» вставляется после раздела foundations, order перенумерован. Связи: корень профессии → `ai-model-landscape` → `ai-prompting` → прикладные компетенции; `prompting + model-landscape` → `ai-workflow-integration`; `model-landscape` → `ai-ethics-rights`.
- **UX/UI**: принятая `canonical/uxui.json` не переписывается. AI-слой добавляется в `model/profession-competencies/uxui.json` на шаге `model:sync` (43 = 34+9), проверка priority-projection скорректирована, чтобы не считать AI-слой частью canonical-карты.

## 4. Evidence и learning-связи

Основание — подтверждённые AI-модули на страницах программ Практикума (короткие темы уроков):

- презентации — «Нейросети для создания презентаций», «Проверка презентации с ИИ», «Репетиция защиты идеи с ИИ»;
- приложения — «Виды нейросетей», «Где нейросети помогают дизайнерам, а где мешают», «ChatGPT / Figma Make / Lovable AI»;
- UX-исследования — «ещё 2 воркшопа по работе с ИИ», «Виды нейросетей», «Архитектура»;
- арт-дирекшн — «Оптимизировать работу с помощью нейросетей», «Составлять брифы и выполнять визуальные задачи с помощью ИИ»;
- 3D / интерьеры / веб — модуль «Нейросети в работе 3D-дизайнера», «Составлять промпты для дизайнерских задач», «Курс с модулем по ИИ»;
- product/motion/graphic — Practicum-тег «Нейросети в дизайне»; motion дополнительно — тема «ai motion» у Motion Design School.

AI-компетенции связаны с программами в `model/learning-source-links.json`. `learning:map`: **107 связанных компетенций, 0 ошибок, 0 предупреждений**; покрытие: UX/UI 40/43, Product 36/39, Motion 35/37, Graphic 26/27, Presentation 21/22, Appdesign 34/35, Uxresearch 26/27, Artdir 24/25, 3D 23/24, Interior 22/23, Web 32/33. Оставшиеся пробелы — узкие AI-темы (AI-ресёрч, AI-видео/аудио, AI-макеты у UX/UI), для них нужен отдельный сбор AI-источников.

## 5. Что пока не сделано

- нет accepted-блоков и тегов для 9 AI-компетенций: `model:validate --require-blocks` для них не проходит;
- в mapping Product/Motion/Graphic AI-компетенции помечены `adjacent` (тег «Нейросети в дизайне») или пустыми (`none`) — тегов-доказательств мало; для остальных профессий mapping-файлов ещё нет;
- UX/UI-канвас (`canvas:page`) строится из canonical-карты и **не показывает** AI-слой; AI-слой виден в `profession-competencies/uxui.json` и в канвасах остальных 10 профессий;
- специализированная библиотека AI-инструментов/курсов пока тонкая — покрытие держится на модулях программ Практикума;
- названия и определения — draft для human-review.
