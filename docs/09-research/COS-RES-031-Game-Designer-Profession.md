# COS-RES-031 — гейм-дизайнер

Профессия `it.game` собрана в модели 2026-11-03 на переиспользованных UX/UI-компетенциях. Эта итерация
добавляет игровой слой компетенций, источники и материалы и **включает профессию в публикацию Beta 1**.

## 1. Что было и что стало

| | До | После |
|---|---|---|
| Компетенции | 30 общих (UX/UI/motion/3D/AI) | 43: 30 общих + **13 игровых** |
| Игровой слой | нет | механики, экономика, прогрессия, левел-дизайн, психология игрока, нарратив, онбординг, гейм-фил, HUD, плейтестинг, движки, live-ops, ИИ в геймдеве |
| Блоки/теги | 30 общих блоков | +13 блоков / +78 тегов (знания и навыки) |
| Источники | общие, без игровой специфики | +14 профильных источников гейм-дизайна |
| Материалы | 0 | 10 принятых материалов (статьи, видео, доклады, документация, курс) |
| Публикация | исключён (`excludedProfessionIds`) | опубликован: 40 компетенций в 5 разделах |

## 2. Игровой слой: компетенции, знания и навыки

| Компетенция | Раздел | Знания | Навыки | Источники |
|---|---|---|---|---|
| **Механики и системное ядро** | Игровые системы и правила | core loop, правила и системы, пространство решений | формулировать core loop, проектировать правила, проверять понятность | GMTK, GDC Vault, Game Developer |
| **Экономика и баланс игры** | Игровые системы и правила | ресурсы/стоки, кривые сложности и прогресса, балансные метрики | моделировать экономику, настраивать сложность, проверять на данных | Machinations, GDC Vault, Game Developer |
| **Прогрессия и награды** | Игровые системы и правила | виды прогрессии, награды и подкрепление, риски гринда | проектировать треки, настраивать награды, проверять темп | GMTK, Game Developer, GDC Vault |
| **Левел-дизайн и пространство** | Игровые системы и правила | чтение уровня, композиция и маршруты, ритм и гейтинг | блок-аут, точки интереса, проверка навигации | Level Design Book, GMTK, GDC Vault |
| **Психология игрока и мотивация** | Игрок и исследование | типы игроков, когнитивная нагрузка, эмоциональные циклы | сегментация, подбор механик, проверка опыта | Extra Credits, GMTK, Game UX Summit |
| **Нарратив и мир игры** | Производство и ИИ | нарративные структуры, лор, нарративный дизайн | писать нарративный дизайн, связывать сюжет и механику, проверять ясность | Extra Credits, GDC Vault, Game Developer |
| **Онбординг и обучение игрока** | Игровой интерфейс и отклик | первый опыт, обучение через механику, раскрытие систем | первые 10 минут, обучение через уровень, проверка на новичках | Game UX Summit, GMTK, Game Developer |
| **Гейм-фил и джус** | Игровой интерфейс и отклик | game feel, отклик и тайминги, джус | настраивать отклик, добавлять обратную связь, проверять ощущение | GMTK, Game Developer, GDC Vault |
| **Игровой интерфейс и HUD** | Игровой интерфейс и отклик | HUD и иерархия, управление и ввод, состояния | проектировать HUD, проверять читаемость, согласовывать с гейм-филом | Game UX Summit, GDC Vault, Game Accessibility Guidelines, Xbox A11y |
| **Плейтестинг и валидация опыта** | Прототипы и плейтесты | гипотезы и сценарии, наблюдение и метрики, анализ | планировать плейтест, проводить сессию, превращать выводы в правки | IGDA, GDC Vault, Game Developer |
| **Движки и прототипирование** | Прототипы и плейтесты | движки и ограничения, прототип vs продакшн, итерации | собрать прототип в движке, проверить механику, подготовить к передаче | Unity Learn, Godot Docs, GDC Vault |
| **Live-ops и монетизация** | Производство и ИИ | live-ops и ритм обновлений, модели монетизации, этика доверия | планировать ивенты, подбирать модель, проверять удержание | Steamworks, Game Developer, GDC Vault |
| **ИИ в геймдеве** | Производство и ИИ | ИИ в генерации контента, ИИ-ассистенты, права и риски | генерировать и проверять контент, вести дизайн с ассистентом, оценивать риски | Game Developer, GDC Vault, GMTK |

## 4. Материалы (Pass E → 10 принято, 4 отклонено)

Приняты с бейджем «Подтвердить»: GMTK (разборы дизайна), The Level Design Book, Game Accessibility
Guidelines, Xbox Accessibility Guidelines, Godot Docs, Machinations, Steamworks Docs, IGDA, Game UX Summit,
Game Developer.

Отклонены Pass E как «канал/агрегатор, а не материал»: YouTube-канал GMTK, GDC Vault (архив), Unity Learn
(каталог курсов), Extra Credits (канал). Для следующей итерации нужны конкретные материалы-страницы
(например, отдельные доклады GDC, отдельные курсы Unity Learn, отдельные видео GMTK), а не хабы.

## 5. Публикация

- `release/beta-1.json`: `it.game` добавлен в `professionIds` (13 профессий), убран из `excludedProfessionIds`.
- Gate: **PASS** — 333/435 связей, 144/144 опубликованных компетенций, 0 пробелов; гейм-дизайнер — 40/43 связей.
- 3 компетенции AI-слоя (`ai-prompting`, `ai-visual-generation`, `ai-ethics-rights`) остаются в профессии,
  но не публикуются: по ADR-015 AI-слой — ядро только AI-дизайнера (правило `coreCompetencyPrefixes`).
  Игровая компетенция «ИИ в геймдеве» получила id `game-ai-gamedev`, чтобы не попадать под AI-слой.
- Source review: +72 автоматических accepted-решения для игровых пар, +3 ручных для «ИИ в геймдеве»
  (`reviewedBy: game-layer-review-v1`), требуется spot-check основателя.
- Прод: https://app.axiona.world/professions/game · скриншот `docs/12-release/reports/screenshots/game-profession-2026-11-14.png`.

## 6. Что дальше

1. Spot-check основателя: 72 решения source review и 10 материалов с бейджем.
2. Конкретные материалы-страницы вместо хабов (доклады GDC, курсы Unity Learn, видео GMTK) — по 2–5 на формат.
3. Расширить игровой слой: жанровые механики, multiplayer/социалка, нарративные инструменты (Ink/Twine),
   игровая аналитика; при необходимости — отдельные блоки.
4. `aggregate --profession game` требует `canonical/game.json` (сейчас модель собирается через общий UX/UI canonical
   + `competencies-extra.json`); для регулярной агрегации добавить canonical-карту игры.
