# COS-RES-031 — гейм-дизайнер

Профессия `it.game` собрана в модели 2026-11-03 на переиспользованных UX/UI-компетенциях. Эта итерация
добавляет игровой слой компетенций, источники и материалы и **включает профессию в публикацию Beta 1**.

## 1. Что было и что стало

| | До | После |
|---|---|---|
| Компетенции | 30 общих (UX/UI/motion/3D/AI) | 46: 30 общих + **16 игровых** |
| Игровой слой | нет | механики, экономика, прогрессия, левел-дизайн, психология игрока, нарратив, онбординг, гейм-фил, HUD, плейтестинг, движки, live-ops, ИИ в геймдеве, мультиплеер/социалка, нарративные инструменты, аналитика |
| Блоки/теги | 30 общих блоков | +16 блоков / +96 тегов (знания и навыки) |
| Источники | общие, без игровой специфики | +23 профильных источника гейм-дизайна |
| Материалы | 0 | 19 принятых материалов (статьи, видео, доклады, документация, курс, конкретные страницы) |
| Публикация | исключён (`excludedProfessionIds`) | опубликован: 43 компетенции в 5 разделах, покрытие Beta 93% |

## 5. Публикация

- `release/beta-1.json`: `it.game` добавлен в `professionIds` (13 профессий), убран из `excludedProfessionIds`.
- Gate: **PASS** — 336/438 связей, 147/147 опубликованных компетенций, 0 пробелов; гейм-дизайнер — 43/46 связей.
- 3 компетенции AI-слоя (`ai-prompting`, `ai-visual-generation`, `ai-ethics-rights`) остаются в профессии,
  но не публикуются: по ADR-015 AI-слой — ядро только AI-дизайнера (правило `coreCompetencyPrefixes`).
  Игровая компетенция «ИИ в геймдеве» получила id `game-ai-gamedev`, чтобы не попадать под AI-слой.
- Source review: +72 автоматических accepted-решения для игровых пар, +3 ручных для «ИИ в геймдеве»
  (`reviewedBy: game-layer-review-v1`), требуется spot-check основателя.
- Прод: https://app.axiona.world/professions/game · скриншот `docs/12-release/reports/screenshots/game-profession-2026-11-14.png`.
- **Штатный агентный прогон (v1.1.0)**: `npm run aggregate -- --profession game --write` — источники → repair → model:sync
  → descriptions → reviews:decide → learning:map/aggregate → release:validate → build:draft; результат — gate PASS
  (336/438 связей, 147/147 компетенций), отчёт `data/aggregation/aggregate-game-2026-11-03.json`.

4. Штатный прогон `aggregate --profession game --write` работает (v1.1.0). `canonical/game.json` пока не нужен:
   global `model:sync` берёт общий UX/UI canonical + `competencies-extra.json`, а игровые разделы и порядок
   задаёт `model/professions/views/game.json`; `model:views --write` применяет их к profession-competencies.
   Если понадобится отдельная canonical-карта игры — добавить её отдельной задачей.
