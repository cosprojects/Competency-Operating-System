# COS-SCN-000 — Сценарии MVP: индекс

## 1. Как пользоваться папкой

Каждый документ — один сценарий: зачем он нужен человеку, как он его проходит и **какими словами** с ним говорит продукт. Тексты готовы к переносу: их можно брать в макеты как есть.

Функциональные элементы здесь **не размечаются**: что и где стоит, определяется на этапе проектирования интерфейса. В документах указано только, какой текст в какой момент появляется и что он должен объяснить.

Служебные ситуации (ошибки, сбои, возвраты) собраны отдельно в `COS-EAR-010` и здесь не дублируются.

| Документ | Сценарий |
|---|---|
| `COS-SCN-001` | Первый вход |
| `COS-SCN-002` | Направление, самооценка, материалы |
| `COS-SCN-003` | Обработка материалов и подтверждение фактов |
| `COS-SCN-004` | Практический кейс, вопросы по темам, наполнение паспорта |
| `COS-SCN-005` | Частичный результат и регистрация |
| `COS-SCN-006` | Полный паспорт и путь развития |
| `COS-SCN-007` | Обратная связь |

## 2. Сквозная логика

| Принцип | Как отражается в текстах |
|---|---|
| Ценность до оплаты | регистрация просится за результат, а не перед началом |
| Никаких ярлыков | говорим о компетенциях и уровнях, не о типе личности и не о «подходящей профессии» |
| Честность про данные | обработка идёт сторонним сервисом по нашему поручению, это названо прямо |
| Честность про точность | без слов «научно доказано», «точно определит» |
| Уважение к времени | в текстах указано, сколько это займёт |

## 3. Сквозные тексты

> Здесь — статичные подписи и ключи. Содержательные сообщения генерирует модель по контракту `COS-COM-008`.

Короткие формулировки, которые повторяются в разных сценариях. Держать их в одном месте, чтобы не расходились.

| Ключ | Текст |
|---|---|
| `product.name` | AXIONA |
| `product.one_liner` | Поймите свой реальный профессиональный уровень, сильные стороны и ближайший шаг для роста — на основе опыта и практики, а не тестов |
| `product.mvp_scope_badge` | Сейчас доступно для профессий в сфере дизайна · другие индустрии скоро |
| `product.time` | 7–10 минут |
| `privacy.short` | Материалы нужны только для разбора ваших навыков. Текст обрабатывается по нашему поручению без сохранения в сторонних базах и без обучения моделей |
| `privacy.link` | Подробнее — в Политике конфиденциальности |
| `quality.disclaimer` | Это не тест на профпригодность и не оценка для найма. Мы разбираем реальные компетенции в выбранном направлении и показываем точки роста |
| `cta.retry` | Попробовать ещё раз |
| `chat.limit_notice` | Помощник отвечает только на вопросы по выбранной компетенции вашего профиля |

## 4. Тон

Говорим с человеком как со взрослым профессионалом: уважительно, ясно, спокойно (`COS-COM-001`).
- **Не навешиваем ярлыков с порога** (не пишем «Вы дизайнер» — на первый экран может зайти любой специалист, инвестор или партнёр; продукт универсален, а дизайн — первая открытая вертикаль).
- **Избегаем рубленых телеграфных обрывков** («Письмо ушло», «Что здесь сломано?») и казённых канцеляризмов («выполняет привлечённый сервис по нашему поручению»).
- В ошибках спокойно объясняем причину и сразу предлагаем рабочий обходной путь.

Примеры плохого и хорошего:

| Плохо | Хорошо |
|---|---|
| «Вы дизайнер. Здесь можно за один проход увидеть, что у вас уже есть» | «Показываем ваш реальный уровень, сильные навыки и слепые зоны — по опыту и практике, а не по тестам» |
| «Что здесь сломано? Назовите 2–3 главные проблемы» | «Какие 2–3 ключевых просчёта или риска вы видите в этом решении?» |
| «Письмо ушло» | «Отправили ссылку для доступа на вашу почту» |
| «Упс! Что-то пошло не так 😔» | «Не удалось прочитать файл. Вы можете вставить описание проекта текстом — разбор сразу продолжится» |

## 5. Что задаётся вне сценариев

- **Срок жизни незарегистрированной сессии** — 30 дней.
- **Кейсов за проход** — один, по полосе, выбранной по самооценке.
- **Вопросов по темам** — до трёх за проход.
- **Язык** — русский; тексты держатся так, чтобы перевод не требовал переписывания логики.
