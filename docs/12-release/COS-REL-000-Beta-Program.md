# COS-REL-000 — AXIONA Beta 1

## 1. Назначение

Документ уточняет календарь и последовательность работ по плану от 28.10.2026, не меняя продуктовую концепцию COS. Диагностика и оценка не отменяются: чтобы диагностировать навыки и знания, сначала нужны нормально собранные профессии, компетенции, знания/навыки и материалы. MVP создаёт эту базу; диагностика — следующий слой. Стратегическая последовательность от Beta до полноценной COS зафиксирована в `COS-BP-005`.

Beta 1 проверяет две вещи:

> 1. Дизайнер может выбрать профессию, понять её структуру, разобраться в знаниях и навыках конкретной компетенции и найти подходящий учебный материал; сохранить важное и вернуться к нему.
>
> 2. Собранная база достаточно корректна, чтобы на неё можно было опереть следующий слой — диагностику и оценку.

Диагностика, оценка уровня, кейсы, паспорт компетенций, адаптивные маршруты и платежи в Beta не входят (`COS-REL-008`, ADR-001), но остаются целевым следующим слоем.

**Статус 2026-10-28:** content gate пройден (`release:validate`: 54/54, 110/110, 0 пробелов). Нормализация AI-assisted; манифест остаётся `draft` до spot-check основателя. Vercel demo собирается из draft-контента; публичный запуск — после `status: ready`, РФ-хостинга и юридического контура.

## 3. Что считается готовым

### Контент

- 54 уникальные компетенции и 110 связей проходят `release:validate`.
- У каждой опубликованной компетенции: определение, 2+ знания, 1+ навык, активный первичный источник с описанием, человеческий sign-off.
- Нет битых ссылок, placeholder-текста, дублей и циклов prerequisites среди опубликованного.
- 26 используемых источников имеют короткое описание; 3 пробела закрыты или компетенции исключены с причиной.
- AI-слой явно исключён и не показывается.

### Продукт

- Пользователь проходит: профессия → компетенция → знания/навыки → материал → вход → материал → сохранение/статус → `/saved` → отзыв.
- Сохранения и статусы переживают выход и повторный вход.
- Отзыв сохраняется и виден в админке; CSV выгружается.
- Ключевые события пишутся; отчёт по метрикам строится.
- Работает на мобильном и десктопе; есть пустые состояния и понятные ошибки.

### Юридическое и инфраструктурное

- Опубликованы политика, условия, cookie notice и согласия с реальными реквизитами ИП.
- Уведомление Роскомнадзора подано до обработки данных.
- Продукт, БД и бэкапы — в РФ; внешних auth/analytics/LLM в runtime нет.
- DNS/TLS, email SPF/DKIM/DMARC, бэкап и восстановление проверены.
- Корпоративный сайт на `axiona.biz`; старые URL редиректят; claims сверены.

### Beta-операции

- 15–25 приглашённых дизайнеров; 10–15 завершили основной сценарий.
- 5+ содержательных отзывов; ошибки контента триажированы.
- Отчёт `COS-REL-006` заполнен фактическими данными и ограничениями выборки.

## 4. Фазы и gates

| Фаза | Дни | Результат | Gate |
|---|---:|---|---|
| 0. Фиксация | 1–2 | Decision log, манифест релиза, quality bar, реестр документов, доступы, CI | Scope заморожен |
| 1. Контент + приложение + legal | 3–14 | 37 компетенций доведены, 26 источников описаны, app scaffold, auth, страницы, legal drafts | Контентный gate: 0 пробелов |
| 2. Интеграция и закрытая Beta | 15–17 | Локальный/закрытый прогон, QA, 10–15 тестеров, исправление блокеров | P0 checklist |
| 3. Vercel demo | 18–21 | Demo-сборка для показа; без реальной публичной регистрации | Внутренний review |
| 4. Публичная Beta | после готовности MVP | `axiona.world` + `axiona.biz`, РФ-хостинг, юридический контур | Все gates, включая публичный запуск |
| 5. Наблюдение | 14 дней после запуска | Использование, ежедневный триаж | Отчёт с данными |
| 6. Решения | после наблюдения | Roadmap, business addendum, investment brief/pitch deck | continue / narrow / pivot |

Даты — ориентиры. Публичный запуск не происходит, пока MVP не готов, контентный и юридический gates не пройдены, а РФ-хостинг не поднят. Vercel demo не заменяет публичный запуск и не открывает реальные регистрации. Если контентный gate срывается, сокращается число профессий, а не quality bar.

## 5. Владельцы

- **Основатель:** продуктовые решения, приёмка контента, юридические входы, приглашения, домены и доступы.
- **Инженерия:** приложение, release pipeline, БД, auth, аналитика, инфраструктура, тесты.
- **Юрист:** документы, РКН, договоры с процессорами.
- **Корпоративный сайт:** отдельный репозиторий/подрядчик.
- **Beta-операции:** основатель + инженерия.

## 6. Главные риски

| Риск | Смягчение |
|---|---|
| 37 компетенций не доведены вовремя | AI-подготовка, батчи, публикация только принятого; при срыве — 2 профессии |
| Основатель не успевает принимать контент | 1–2 часа/день, фиксированные слоты, AI-превью |
| Юрист/РКН не готовы | Начать в день 1; без sign-off не публиковать |
| `axiona.biz`/репозиторий недоступны | Fallback `app.axiona.world`; доступ к репо — dependency дня 3 |
| Email-доставка magic link | SPF/DKIM/DMARC, тесты Gmail/Яндекс/Mail.ru |
| Аналитика без согласия | Consent banner; отказ работает; allowlist событий |
| Расползание scope | ADR-001/009: диагностика, платежи, AI-слой вне Beta |
| Сайт обещает лишнее | Claims-аудит до анонса |
| Секреты в локальной среде | Ротация DeepSeek key; `.env*` вне git |
