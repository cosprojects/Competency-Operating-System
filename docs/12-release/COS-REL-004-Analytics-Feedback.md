# COS-REL-004 — Аналитика и обратная связь Beta 1

## 1. Принципы

- Собираем только то, что помогает понять путь пользователя и качество контента.
- В событиях нет email, имени, текста отзывов, сырого IP и содержимого материалов.
- Аналитика first-party; при отказе от согласия продукт работает без событий.
- Метрики на малой выборке — ориентиры, а не доказательство спроса.
- Отзыв без сохранения и обработки не считается обратной связью.

## 2. События

| Событие | Момент | Параметры | Назначение |
|---|---|---|---|
| `page_view` | Загрузка страницы | `path`, `locale`, `referrer_type` | Входящий интерес |
| `profession_view` | Открытие профессии | `profession_id` | Востребованные направления |
| `competency_view` | Открытие компетенции | `profession_id`, `competency_id` | Интерес к составу |
| `source_click` | Переход к материалу | `competency_id`, `source_id`, `source_kind`, `access` | Интерес к материалам |
| `source_gate_view` | Показ требования входа | `competency_id`, `source_id` | Барьер регистрации |
| `signup_start` | Начало регистрации | `method` | Воронка входа |
| `signup_complete` | Успешный вход/создание | — | Конверсия |
| `favorite_add` / `favorite_remove` | Избранное | `target_type`, `target_id` | Намерение вернуться |
| `study_status_change` | Смена статуса | `competency_id`, `from`, `to` | Использование развития |
| `feedback_open` | Открытие формы | `context`, `target_type?` | Активность обратной связи |
| `feedback_submit` | Отправка | `feedback_type`, `target_type?`, `has_rating`, `has_comment` | Объём и типы |
| `return_visit` | Повторная сессия | `days_since_signup` | Удержание |

Правила:
- `path` — без query-параметров и email.
- `referrer_type` — `internal` / `external` / `none`; не сохраняем полный referrer.
- `source_id` — ID реестра, не URL с query.
- `props` валидируется allowlist; неизвестные поля отбрасываются.
- Событие без согласия не пишется; серверные security-логи не являются аналитикой.

## 3. Метрики

| Метрика | Определение | Знаменатель | Ограничение |
|---|---|---|---|
| Посетители | Уникальные `anonId` с `page_view` | — | Только согласившиеся |
| Регистрации | Уникальные `userId` с `signup_complete` | — | За период |
| Конверсия в регистрацию | Регистрации / посетители | Посетители | Не сравнивать периоды с разной длиной |
| Открыли компетенцию | Уникальные `anonId/userId` с `competency_view` | Посетители | Один пользователь считается один раз |
| Открыли материал | Уникальные `userId` с `source_click` | Зарегистрированные | Материал за гейтом |
| Сохранили | Уникальные `userId` с `favorite_add` | Зарегистрированные | Хотя бы одно сохранение |
| 7-дневный возврат | Зарегистрированные с активностью на 7–14 день | Зарегистрированные ≥7 дней назад | Малая выборка |
| Обратная связь | Количество и типы `feedback_submit` | — | Смотреть тексты, не только числа |

Отчёт: `npm run metrics:report -- --days 30 --write` или админ-страница `/admin/metrics`. В отчёте всегда указывать размер выборки и период.

## 4. Обратная связь

### Типы

- `CONTENT_ERROR` — ошибка или неточность.
- `MISSING_COMPETENCY` — не хватает компетенции или навыка.
- `BAD_MATERIAL` — не подходит материал.
- `MISSING_FEATURE` — не хватает функциональности.
- `IMPROVEMENT` — предложение.
- `GENERAL` — общий отзыв.

### Поля

- тип — обязателен;
- объект (`targetType`/`targetId`) — автоматически для контекстной формы;
- оценка полезности 1–5 — опционально;
- комментарий — опционально, до 4000 символов;
- email для ответа — опционально;
- `pagePath` — автоматически.

Требование: хотя бы одно из полей «оценка» или «комментарий». Имя и телефон не собираются.

### Обработка

- Сохранение в `Feedback`; пользователь видит подтверждение.
- Админка: фильтры по типу, статусу, объекту; просмотр; CSV.
- Статусы: `NEW` → `TRIAGED` → `RESOLVED`.
- Еженедельный триаж: ошибки контента → в контентный backlog; функциональные → в post-Beta; повторяющиеся темы → в отчёт.
- Ответ пользователю — только если он оставил email и запросил ответ.

### Анти-спам

- Honeypot-поле.
- Rate limit: 5 отзывов/час на сессию/IP-хэш.
- Лимит длины и запрет HTML.
- Подозрительные отзывы сохраняются, но помечаются; не удаляются молча.

## 5. Согласие и retention

- Необходимые cookie: сессия.
- Аналитическая cookie `aid` — только после согласия; отказ не блокирует продукт.
- Cookie notice и баннер; ссылка на политику.
- Сроки: login tokens — 24 часа; сессии — 30 дней; аналитика — 180 дней; отзывы — 12 месяцев после решения; удаление аккаунта — немедленно.
- Удаление аккаунта удаляет избранное, статусы, сессии и отзывы; события анонимизируются (`userId = null`).
- Экспорт отзывов — только админ; CSV без формул-инъекций.

## 6. Что не делаем в Beta

- Тепловые карты, записи сессий, A/B-тесты, внешние трекеры.
- Сбор email в аналитику.
- Автоматическую LLM-классификацию отзывов.
- Дашборд с «красивыми» графиками вместо проверяемых определений метрик.
