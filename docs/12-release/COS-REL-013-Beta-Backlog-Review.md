# COS-REL-013 — Beta backlog на апрув

## 1. Почему этот документ

37 GitHub issues были созданы до согласования детального плана. Они считаются **черновиками**:

- новые issues не создаются;
- существующие issues не обновляются;
- `tasks:sync --update` не запускается;
- после апрува обновляем описания, зависимости и acceptance в тех же issues.

Цель — сделать задачи исполняемыми: контекст, результат, зависимости, границы и критерии готовности.

## 2. Что меняется в задаче

В `tasks/tasks.json` добавлены поля:

- `context` — зачем задача и что уже известно;
- `deliverable` — какой артефакт/результат должен появиться;
- `outOfScope` — что в эту задачу не входит;
- `dependsOn` — от каких задач зависит;
- `acceptance` — проверяемые критерии;
- `version`, `stage`, `area`, `priority`, `status`.

`tasks:sync --update` перезапишет issue body этими полями. Номера issues сохранятся.

## 7. Что будет после апрува

1. Ты вносишь правки в этот документ или в `tasks/tasks.json`.
2. Я обновляю `tasks/tasks.json` и запускаю `tasks:sync -- --update`.
3. Issues получают контекст, зависимости, deliverable, out-of-scope и acceptance.
4. Milestones/labels обновляются; новые issues не создаются, если не согласовано разбиение T-002.
5. Project: добавляем существующие issues и поля (нужен classic PAT с `project`).

## 8. Classic PAT

Для Project API:

1. https://github.com/settings/tokens/new
2. Note: `AXIONA project sync`; expiration 90 дней.
3. Scopes: `public_repo`, `project`.
4. Generate token.
5. В `tasks/.env.local` добавить отдельной строкой:

```bash
PROJECT_TOKEN=ghp_...
```

`GH_TOKEN` (fine-grained) оставить для issues. `PROJECT_TOKEN` не коммитить.

## 9. Решения (утверждено 2026-10-28)

1. **T-002** остаётся одним epic с чек-листом; на подзадачи не дробится.
2. **Существующие 37 issues** обновляются, а не пересоздаются. Номера #1–#37 сохранены.
3. **Дальние версии** (v0.3.0–v1.0.0, 25 задач) переведены в `deferred` и закрыты до планирования соответствующей версии. В активном канбане остаются 12 issues: T-001–T-003 и T-005–T-013.
4. **Границы v0.2.0** — 9 задач. P0 обязательны; T-010/T-011/T-012 (P1) могут перейти в v0.3.0, если поджимает время.

### Что сделано после апрува

- `tasks/tasks.json`: добавлены `context`, `deliverable`, `outOfScope`, `dependsOn`, `deferred`.
- `tasks:sync --update`: обновлены 37 issues; 25 закрыты как deferred; 12 активных открыты.
- Новые issues не создавались.
- В issue body появились контекст, зависимости, результат, out-of-scope и acceptance.

### Как вернуть отложенную задачу

1. Убрать `deferred: true` у задачи в `tasks/tasks.json`.
2. Перевести `status` в `Backlog`/`Ready`.
3. Запустить `npm run tasks:sync -- --version <version> --update`.
4. Задача переоткроется, milestone/labels сохранятся.
