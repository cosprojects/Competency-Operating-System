## Что сделано

- **3 источника добавлены** для пробелов:
  - `nngroup-ethics` — [NN/g Ethics](https://www.nngroup.com/topic/ethics/) для `ux-ethics-privacy`;
  - `framer-learn` — [Framer Learn](https://www.framer.com/learn/) для `ui-framer`;
  - `reforge-blog` — [Reforge Blog](https://www.reforge.com/blog) для `product-growth`.
- **26 summary** добавлены источникам, используемым четырьмя профессиями. Реестр: 121 источник, 92 active.
- **53 блока** нормализованы: теги получили `sourceRefs` и `evidenceState: supported`; блокам с неполным составом добавлены знания/навыки.
- **34 общих тега** заменены на конкретные формулировки (например, «Практика раздела…» → «Готовить макет к печати»).
- **16 дублей названий** knowledge/skill разведены через «Понятие: …».
- **40 тегов** с placeholder-определением «Тема/навык на странице программы…» получили конкретные определения (126 вхождений в блоках).
- **128 решений source review** записаны в `release/beta-1-source-review.json`; все — `accepted`.

## Важная оговорка

Это **AI-assisted нормализация**, а не финальная человеческая приёмка. Решения source review подписаны `deepseek-content-gate`; часть `sourceRefs` привязана на уровне блока/источника, а не построчно проверена основателем. Поэтому:

- `release/beta-1.json` остаётся в статусе `draft`;
- `release:build` публичной версии не запускается, пока основатель не сделает spot-check и не переведёт статус в `ready`;
- рекомендованный spot-check: 54 компетенции, 29 карточек источников, 34 заменённых тега.

## Следующие действия

1. Основатель проверяет выборку: по одному блоку каждой профессии + все 3 новых источника + 5–10 заменённых тегов.
2. Если замечаний нет — `release/beta-1.json` → `"status": "ready"`.
3. `npm run release:validate && npm run release:build`.
4. `npm run web:build` / Vercel deploy.
5. Для публичного запуска — РФ-хостинг, PostgreSQL, юридический контур; Vercel demo остаётся demo.
