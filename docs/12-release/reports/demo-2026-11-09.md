## 3. Ограничения demo

- Vercel preview может быть закрыт Vercel SSO; для внешнего показа нужен доступ через dashboard или настройка защиты.
- Нет production PostgreSQL и бэкапов: вход, сохранения, админка и отзывы требуют БД; без неё доступен анонимный просмотр.
- Реальные персональные данные на Vercel demo не собираем; публичная регистрация должна быть закрыта до VDS/legal.
- Миграции на demo-БД не применены автоматически, если `DATABASE_URL` не задан.
- Продукт ещё не на VDS; следующий шаг — контур `app.axiona.world` с PostgreSQL.
- `/profile` ещё не реализован; `/account` остаётся страницей аккаунта.
- Некритичные расхождения human spot-check ведутся отдельно; манифест `ready`.
