- `I404:21022;404:21070` 1. Что такое компонент
- `I404:21022;404:21071` Компонент (Component) — это повторно используемый элемент интерфейса, который создается один раз и может применяться в разных частях макета. Компонент может представлять собой кнопку, поле ввода, карточку товара, иконку, навигационное меню или целый блок интерфейса.

Главная задача компонентов — обеспечить единообразие интерфейса и упростить его поддержку. Если один и тот же элемент используется на нескольких экранах, нет необходимости каждый раз создавать его заново. Достаточно создать компонент и использовать его копии — экземпляры (Instances).
Например, в интерфейсе интернет-магазина может быть несколько десятков кнопок «Добавить в корзину». Вместо того чтобы рисовать каждую кнопку отдельно, дизайнер создает один компонент и размещает его экземпляры в нужных местах. Все экземпляры связаны с исходным компонентом и наследуют его структуру и свойства.
Если изменить основной компонент — например, увеличить скругление углов или изменить типографику, — соответствующие изменения автоматически отразятся на его экземплярах. При этом локальные изменения, внесенные непосредственно в отдельный экземпляр, могут сохраняться как переопределения (Overrides).
Таким образом, компоненты позволяют централизованно управлять повторяющимися элементами интерфейса.

- `I404:21022;404:21073` Варианты (Variants) — это механизм Figma, который позволяет объединять несколько связанных компонентов в один набор (Component Set). Каждый компонент внутри такого набора представляет собой определенное состояние или модификацию одного и того же элемента интерфейса.
Например, кнопка может иметь несколько состояний:
Default — обычное состояние;
Hover — состояние при наведении курсора;
Pressed — состояние при нажатии;
Disabled — неактивное состояние.
Вместо того чтобы хранить каждое состояние как отдельный независимый компонент, их можно объединить в один набор вариантов. После этого дизайнер сможет выбирать нужное состояние кнопки через панель свойств экземпляра.
Варианты также применяются для описания визуальных и функциональных модификаций элемента. Например, одна и та же кнопка может иметь несколько размеров (Small, Medium, Large), типов оформления (Primary, Secondary, Tertiary) или состояний доступности.
Важно понимать, что вариант — это не просто копия компонента с другим цветом или размером. Это отдельная конфигурация одного компонента внутри общей системы. Все варианты объединены общей логикой, именованием и назначением.
