## Как снимался контекст (важно для следующих сессий)

```sh
node ~/Documents/dsh-skills/tools/figma-snapshot.mjs \
  --url "https://www.figma.com/design/UfuaPpLJA31DeBSObX5xNJ/AXIONA---mvp?node-id=369-14582&m=dev" \
  --nodes 369:14582 --depth 12 --images png --out docs/design/figma --force
```

Причина, по которой предыдущая сессия «теряла» контекст: `figma-snapshot.mjs` пишет
`meta.json` **до** проверки кэша. Любой запуск, который только обновил мету, записывает в
`meta.json` новый `lastModified`, после чего следующий запуск видит «Кэш актуален» и
оставляет старые `nodes/*.json`. В нашем случае файл менялся 19.11 в 18:49 и в 20:30,
а узел главной лежал от 19:04. Лечение: сверять `meta.json.lastModified` с mtime
`nodes/369-14582.json` и обновлять узлы с `--force`.
