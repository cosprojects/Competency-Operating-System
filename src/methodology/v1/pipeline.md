# Пайплайн методики

Список команд и порядок их запуска хранятся в `src/methodology/v1/pipeline.json`. Это файл, который читает агент. Описание шага, команда и зависимости лежат в одной записи.

Агент выполняет реестр целиком:

```bash
npm run pipeline
```

Показать команды, ничего не запуская:

```bash
npm run pipeline -- --dry-run
```

Начать с шага или выполнить один:

```bash
npm run pipeline -- --from 3
npm run pipeline -- --only methodologist-patch
```

Каждый прогон дописывает результат в `data/competency-candidates/pipeline-run.json`: какая команда шла, с каким кодом она закончилась, что пропущено. Шаг с `"executor": "human"` агент не запускает. Если у шага нет требуемого файла или команда завершилась с ошибкой, следующие шаги не стартуют.
